# 3D Webinar Website

A 3D-inspired webinar website created as a web development project with a focus on creating an engaging and visually appealing user interface.

## 🌐 Live Demo

[View Live Website](https://3-d-webinar-a8b5egyi5-nexus-34dd.vercel.app/)

## 📌 Project Overview

This project is a webinar website designed with a modern 3D-style visual experience.

The website was developed as a practical web development project and deployed using Vercel so that it can be accessed online.

## ✨ Features

* Modern 3D-style website design
* Responsive web interface
* Webinar-focused layout
* Clean and interactive user interface
* Deployed and accessible online

## 🛠️ Technologies Used

* HTML
* CSS
